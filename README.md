## My interactive website project, built with HTML, CSS, and JavaScript.

**Note: This project was created as part of my programming learning journey.**

## Features
* Persona 5 Inspired UI
* Interactive Carousel & Paginatio
* Single Page Action Navigation
* Responsive 16:9 Stage

## Installation
1. Clone or download this repository.
2. Extract the `images.zip` file into the same folder as `index.html` and `style.css`.
3. Open `index.html` in any web browser.
